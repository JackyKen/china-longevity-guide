# 中国人健康长寿实操指南

把寿命的天花板交给科学，把底线交给自己。

这是一部面向当代中国普通读者的开源科普读本。正文约 15 万字，依据世界卫生组织、国家卫生健康委员会、中国疾病预防控制中心、国家癌症中心、国家心血管病中心、中国营养学会等机构的公开指南与报告，以及大型队列研究和随机对照试验写成。它帮助读者理解健康与衰老的机制，并把原则落实到餐桌、运动、睡眠、体检和家庭决策中。

完整书稿见：[中国人健康长寿实操指南.md](./中国人健康长寿实操指南.md)

## 阅读之前

本书不能替代执业医师的问诊、检查、诊断、处方或个体化治疗建议。文中的数字、切点和行动清单，是人群层面的参考，会因年龄、性别、既有疾病、用药和家族史而不同。凡涉及用药、停药、检验异常、手术、肿瘤筛查阳性和慢性病管理，请在合格医师指导下进行。

## 这本书写了什么

全书以五篇二十五章展开：

1. **认清本质**：健康寿命、衰老的第一性原理、当代中国人的健康画像，以及如何判断一条健康信息是否可靠。
2. **身体的本金**：肌肉、心脏与血管、代谢、大脑、睡眠、消化与炎症，以及肾、免疫、口腔与感官。
3. **每天可做的事**：运动处方、中国餐桌、烟酒与环境、压力和亲密关系。
4. **医学、传统与科技**：体检与早筛、药物与干预、疫苗、人生阶段、中医养生中经得起检验的部分，以及人工智能尚未兑现的承诺。
5. **把知识过成生活**：照顾老人与自己同时老化，以及一份可执行的一年计划。
